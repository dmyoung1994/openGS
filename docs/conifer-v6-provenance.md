v6 is an isolated candidate-only derivative. It does not modify or replace
v3/v4/v5, the production catalog, `Trees.js`, viewer mappings, course data, or
benchmark definitions.

The deterministic bake uses the v4 36-layer/8-branch rhythm and real tapered
trunk/primary branches. Each local branch/whorl neighborhood receives one
tightly fitted composite macro sprite; LOD0 crosses an angled pair, while LOD1
keeps one card per whorl branch and a two-sided structural scaffold. The cards
are local macro clusters, not whole-tree billboards and not thousands of tiny
runtime twig cards. Macro atlas RGB/alpha is composed directly from the source
maps and contains no sun, AO, shadow, or emission.

The macro atlas is 1024×1024 RGBA. At the runtime 16/255 cutoff, its 15 foliage
tiles measure coverage range `0.3383…0.5053`, mean `0.4259`. Tile 0 is opaque
source bark for the shared material.
