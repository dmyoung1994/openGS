The maintained-course derivative keeps the source's green-canopy and two bark
PBR materials, eight embedded 2K WebP maps, UV sets, vertex colours, normals,
double-sided foliage, and authored leaf alpha. The source's separate
`MI_MWPalmTree_Canopy_02` dry-frond primitive is intentionally pruned so the
course reads as maintained living palms rather than a dead brown skirt. No
billboard, atlas, procedural substitute, or diffuse-only material bake is used.

LOD0 is the source GLB decoded from Draco by glTF-Transform 4.4.2 so the existing
production Meshopt-capable loader can read it without adding a second geometry
decoder. LOD1 is generated by `scripts/process_blendkit_palm.py` in Blender 5.2,
using a 0.42 collapse ratio per source mesh, then Meshopt-compressed. Both LODs
retain the same four live-canopy/bark primitive slots.
