# Poly Haven tree kit promotion

The runtime tree catalog is CC0 Poly Haven only. The Premium Range exercises the
kit as authored pieces rather than multiplying one existing tree record.

Sources:

- [Fir Tree 01](https://polyhaven.com/a/fir_tree_01)
- [Pine Tree 01](https://polyhaven.com/a/pine_tree_01)

Promoted records:

| Catalog ID | Runtime role | Local derivatives |
| --- | --- | --- |
| `polyhaven-fir-tree-01` | animated LOD pair + baked atlas | `fir_tree_01_lod0.glb`, `fir_tree_01_lod1.glb`, `fir_tree_01_impostor.png` |
| `polyhaven-fir-tree-01-variant-b` | direct hero prop | `fir_tree_01_variant_b_lod0.glb` |
| `polyhaven-fir-tree-01-variant-c` | direct hero prop | `fir_tree_01_variant_c_lod0.glb` |
| `polyhaven-pine-tree-01` | animated LOD pair + baked atlas | `pine_tree_01_canonical_lod0.glb`, `pine_tree_01_canonical_lod1.glb`, `pine_tree_01_impostor.png` |

The two Fir variants intentionally use the non-impostor prop path: they are
small-count silhouette pieces, while the canonical Fir and Pine records own the
repeatable LOD/atlas path. Every derivative is hash-checked by the catalog before
the Premium Range becomes visible.
