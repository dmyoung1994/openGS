# Agent environment commands

Use the canonical command reference at `../../golf-course-authoring/references/agent-environment-commands.md`.

The essential rule is: use `environmentAssembly` for tree communities and rock outcrops, `dressCourseEdge` for native-to-maintained transitions, `place` for solitary accents, and `scatter` only for broad secondary masses. All catalog selections must be licensed, biome-compatible, deterministic, and outside protected play.
